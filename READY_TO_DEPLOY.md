## 🚀 Quick Launch (3 Steps)

### Step 1: Change Admin Password
Edit `constants.tsx`:
```typescript
export const ADMIN_KEY = 'your-secure-password-here';
```

### Step 2: Push to GitHub
```bash
git add .
git commit -m "Production ready"
git push
```

### Step 3: Deploy on Vercel
1. Go to [vercel.com](https://vercel.com)
2. Click "Import Project"
3. Select your GitHub repo
4. Click "Deploy"
5. **Done!** Site is live in 1-2 minutes ✅

## 💡 Tips

**For Best Results:**
1. **Use high-quality audio** - 128-256kbps MP3s recommended
2. **Compress images** - Use tinypng.com for faster loads
3. **Descriptive titles** - Help users find content
4. **Regular backups** - The files are safe on Vercel Blob, but keep copies
5. **Monitor storage** - Vercel Blob has 1TB free (plenty!)

## 🆘 Need Help?

### Common Issues

**Q: How do I make changes?**  
A: Edit code → `git push` → Vercel auto-deploys in 1-2 min

**Q: Password not working?**  
A: Check `constants.tsx` ADMIN_KEY, hard refresh browser

**Q: Upload fails?**  
A: File too large? Try compression. Check browser console for errors.

**Q: Want custom domain?**  
A: Buy domain → Add to Vercel settings → 24hr propagation

**Q: How to backup files?**  
A: Vercel Blob is redundant. You can also download files from Vercel dashboard.

See [DEPLOYMENT.md](DEPLOYMENT.md) for more troubleshooting.
